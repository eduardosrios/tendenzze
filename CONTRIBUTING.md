# Contributing

Thank you for your interest in Tendenzze.

This is a proprietary project. Public visibility on GitHub does not grant permission to reuse, copy, modify, distribute, commercialize, or create derivative works from the source code. Contributions may be reviewed at the discretion of the repository owner.

## Contribution Guidelines

- Keep all project-facing text in English.
- Match the existing stack: HTML, CSS, and JavaScript.
- Do not introduce React or another application framework unless requested by the repository owner.
- Keep changes focused and directly related to the project.
- Do not add local instruction files, scratch files, temporary files, downloaded prompt files, or unrelated assets.
- Prefer semantic HTML, responsive CSS, accessible interactions, and progressive enhancement.
- Use clear filenames and keep assets organized.

## Pull Requests

Pull requests should include:

- A short summary of the change.
- A concise description of visible UI changes.
- Any manual test steps used to verify the result.
- Notes about accessibility, responsiveness, or browser behavior when relevant.

## Ownership

By submitting a contribution, you agree that the repository owner may use, modify, or reject the contribution within the proprietary project. No license is granted to you beyond the repository owner's written permission.
