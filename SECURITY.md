# Security Policy

## Supported Scope

Security reports for Tendenzze should focus on files and behavior maintained in this repository.

This project is planned as a static HTML, CSS, and JavaScript website. There is currently no backend service, database, authentication system, or administrative panel in scope.

## Reporting a Vulnerability

If you believe you found a security issue, contact the repository owner through the GitHub profile associated with this repository.

Please include:

- A clear description of the issue.
- Steps to reproduce the behavior.
- Affected files, URLs, or browser environments.
- Potential impact.
- Any suggested remediation, if known.

## Responsible Disclosure

Do not publicly disclose vulnerabilities before the repository owner has had a reasonable opportunity to review and address the report.

## Out of Scope

The following are generally out of scope unless they directly affect this repository:

- Issues in third-party platforms or CDNs.
- Browser extensions or local user environment problems.
- Social engineering.
- Denial-of-service testing.
- Automated scanner output without a practical impact explanation.
