# Code of Conduct

## Our Standards

Tendenzze is maintained as a professional project space. Everyone participating in this repository is expected to communicate with clarity, respect, and focus.

Expected behavior includes:

- Using respectful and inclusive language.
- Keeping feedback constructive and relevant to the project.
- Respecting different experience levels and professional backgrounds.
- Prioritizing project quality, maintainability, accessibility, and user value.
- Avoiding personal attacks, harassment, discrimination, or disruptive conduct.

## Unacceptable Behavior

Unacceptable behavior includes harassment, insults, intimidation, discriminatory language, spam, doxxing, repeated off-topic comments, or any behavior that makes collaboration unsafe or unproductive.

## Enforcement

Project maintainers may remove comments, reject contributions, close issues, restrict participation, or take other appropriate action when this Code of Conduct is violated.

## Reporting

To report a concern, contact the repository owner through the GitHub profile associated with this repository. Reports should include relevant dates, affected areas, and context when possible.
